# Project-Sanjeevani
AI Powered Road Accident Detection and Emergency Response System

### Objective
To detect road accidents, analyze severity using AI, and generate emergency response recommendations.

### Features
- Accident Detection
- Severity Analysis
- Emergency Alert Generation
- AI Assisted Decision Support
- LM Studio Integration

### Tech Stack
- Python
- Flask
- LM Studio
- OpenCV
- HTML/CSS/JavaScript
